### Секция настроек карты
```toml
[world]
width = 15
height = 10
```
Данная секция задаёт настройки размера карты.  
Значения параметров целые положительные числа
### Секция настроек существ
```toml
[herbivore]
health = 10
speed = 2
```
Данная секция задаёт настройки травоядного.  
Количество единиц жизни и скорость перемещения - целые положительные числа.
```toml
[predator]
health = 10
speed = 2
attack_power = 3
```
Данная секция задаёт настройки хищника.  
Количество единиц жизни, скорость перемещения и  
сила атаки - целые положительные числа.
### Секция настроек инициализации симуляции
```toml
[spawn_limit]
predator = 10
herbivore = 10
tree = 10
grass = 10
rock = 10
```
Данная секция задаёт настройки количества сущностей на карте перед началом симуляции.  
Количество единиц каждого типа сущностей - целые положительные числа.
### Секция настроек добавления ресурсов
```toml
[balance_grass]
count = 3
remaining = 3
```
Данная секция задаёт настройки для травы.  
Количество единиц ресурса и лимит оставшихся ресурсов на карте  
после которого будет добавлено заданное в первом параметре  
количество - целые положительные числа.
```toml
[balance_herbivore]
count = 3
remaining = 3
```
То же что и предыдущая секция, только для травоядного.
### Секция настройки отображения
```toml
[icons]
predator = "🐺 "
herbivore = "🐇 "
grass = "🌿 "
rock = "🪨 "
tree = "🌳 "
default = "🟧 "
```
В данной секции задаются иконки(или символы) для вывода в консоль(отрисовка карты с расположенными сущностями). Значения строковые.  
Иконки можно подобрать [здесь](https://symbl.cc/ru/)
